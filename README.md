# aurachirurgie.jetzt

Statische Website für [aurachirurgie.jetzt](https://aurachirurgie.jetzt).

## Projekt

- `index.html` – Startseite
- `impressum.html` – Impressum
- `datenschutz.html` – Datenschutzhinweise
- `assets/styles.css` – Gestaltung
- `assets/script.js` – Navigation, Cookie-Hinweis und Formularstatus
- `send.php` – Versand des Kontaktformulars auf dem Live-Server

Die Live-Website wird bei ALL-INKL gehostet. Zugangsdaten und andere Geheimnisse
gehören nicht in dieses Repository.

## Lokal ansehen

Die Startseite kann direkt im Browser geöffnet werden:

```sh
open index.html
```

Das Kontaktformular benötigt einen Webserver mit PHP und funktioniert daher
nicht in der reinen Dateivorschau.
